Każdy blog programisty musi zacząć się tak samo. Tradycja to tradycja:

HelloWorld.java
void main() {
    IO.println("Hello, World!");  // tak, w nowej Javie to naprawdę tyle
}

Nazywam się Robert, piszę backend w Javie i to jest moja wizytówka. Będzie o architekturze heksagonalnej, o DDD traktowanym serio (agregaty, które naprawdę czegoś pilnują, a nie worki na settery) i o frameworkach: od zawsze robię w Springu, a od niedawna odkrywam alternatywy — Quarkus, Micronaut, wpadły mi też jakieś Helidony i inne wynalazki. Sprawdzę je za was. Część wpisów po polsku, część po angielsku — zależnie od tematu.

Pełna transparentność

Tę stronę zaprojektował i napisał mi Claude. Ja mówiłem, co chcę (czerń, szarość, granat, klimat IntelliJ), on pisał. Trochę jak code review na odwrót — i szczerze? Wyszło szybciej niż moje typowe „jeszcze tylko poprawię CSS".

To zresztą dobry temat na start: jak zmienia się nasza robota, kiedy część kodu piszą modele. Spoiler — architektura robi się ważniejsza, nie mniej ważna. Ktoś musi wiedzieć, gdzie kończy się domena, a zaczyna adapter. O tym będzie następny wpis.

Every developer blog has to start the same way. Tradition is tradition:

HelloWorld.java
void main() {
    IO.println("Hello, World!");  // yes, in modern Java that's really it
}

My name is Robert, I write Java backends and this blog is my business card. Expect hexagonal architecture, DDD taken seriously (aggregates that actually guard something, not bags of setters) and frameworks: I've always worked in Spring, and lately I'm exploring the alternatives — Quarkus, Micronaut, plus some Helidons and other curiosities that crossed my radar. I'll test them so you don't have to. Some posts in Polish, some in English — depending on the topic.

Full transparency

This site was designed and written for me by Claude. I said what I wanted (black, grey, navy, IntelliJ vibes), it wrote the code. A bit like code review in reverse — and honestly? Faster than my usual "just one more CSS tweak".

Which is a good opening theme: how our job changes when models write part of the code. Spoiler — architecture becomes more important, not less. Someone has to know where the domain ends and the adapter begins. That's the next post.
